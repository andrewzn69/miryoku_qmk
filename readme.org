* Build and flash: splitkb Kyria rev3

#+begin_src sh
nix-shell --run "qmk compile -kb splitkb/kyria/rev3 -km manna-harbour_miryoku -e CONVERT_TO=promicro_rp2040 -e MIRYOKU_ALPHAS=COLEMAK_DH -e MIRYOKU_MAPPING=EXTENDED_THUMBS"
#+end_src

Per half, in the bootloader (the 128M drive in =lsblk=):

#+begin_src sh
sudo mount -o sync /dev/sdXN /mnt/temp
sudo cp splitkb_kyria_rev3_manna-harbour_miryoku_promicro_rp2040.uf2 /mnt/temp/
#+end_src
